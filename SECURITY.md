# Security policy

Please do not open a public issue for a suspected credential leak, unauthorized access, or privacy incident.

Report security concerns to [michael@iovannemusicacademy.com](mailto:michael@iovannemusicacademy.com) with:

- a short description of the issue;
- the affected page or component;
- the approximate time it was observed; and
- reproduction details that do not include secrets or private message content.

Do not commit service-account keys, OAuth tokens, Pub/Sub credentials, local `.env` files, or copied Chat messages to this repository.
