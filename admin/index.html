Google Chat authorization

The Chat app uses the standard bot interaction scope for ordinary Chat interactions. Proactive message and reaction subscriptions use:

https://www.googleapis.com/auth/chat.app.messages.readonly

Google Workspace administrator approval is required for that chat.app.* scope. The Marketplace listing is private to the Workspace domain and is intended for authorized organizational users.

Event delivery

Google Workspace Events delivers Chat events through a Google Cloud Pub/Sub topic to the operator-controlled Hermes host. Hermes filters bot-originated messages and applies its response policy before deciding whether to answer.

Space membership

Proactive watching is limited to spaces where Hermes is a member and where the relevant Workspace authorization and subscription are active. Adding Hermes to a new space may require a membership refresh before proactive observation begins.

Model and memory

The deployment is intended to use an operator-controlled model endpoint. Conversation memory and retention are configuration-dependent. Administrators should review the active Hermes configuration before changing the model provider, memory behavior, or retention settings.
